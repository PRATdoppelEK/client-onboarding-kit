## 🎯 What This Is

A complete onboarding kit for introducing AI solutions to non-technical clients.
Designed for inverter manufacturers, franchise operators, energy companies, and CA firms.

Available in **English and German**.

## 🎓 Workshop Guide

`workshop/WORKSHOP_GUIDE.md`

A complete 2-hour client workshop:

| Time | Section |
|---|---|
| 0:00–0:15 | Welcome + what's your biggest pain point? |
| 0:15–0:35 | What is AI? (plain language) |
| 0:35–0:55 | Live demo (inverter / franchise / tender) |
| 0:55–1:15 | Where does AI fit in your workflow? |
| 1:15–1:40 | ROI calculation together on whiteboard |
| 1:40–2:00 | Q&A + next steps |

Includes:
- Facilitator scripts for each section
- Demo scripts for inverter, franchise, and tender tools
- Common objections + responses
- Post-workshop follow-up email template
